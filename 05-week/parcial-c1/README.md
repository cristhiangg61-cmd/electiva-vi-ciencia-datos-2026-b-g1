# Diagnóstico de caso de negocio — Mantenimiento predictivo (Siemens)

Se trabaja el caso de mantenimiento predictivo de motores y equipos en una planta manufacturera de Siemens: los equipos operan de forma continua y están expuestos a desgaste, y el objetivo es usar los datos que ellos mismos generan para anticipar una falla antes de que detenga la producción.
