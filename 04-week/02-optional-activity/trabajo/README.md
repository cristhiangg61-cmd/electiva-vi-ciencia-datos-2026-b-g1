## Problem & data

The selected problem is predictive maintenance for industrial motors and production equipment in a manufacturing plant. Unexpected equipment failures can stop production, increase repair costs, and cause delays in deliveries. The data needed includes temperature, vibration, electrical consumption, pressure, operating hours, previous failures, and maintenance records. These data can be collected from IoT sensors, industrial monitoring platforms, and ERP or CMMS systems. The main type of analytics is predictive analytics because the objective is to estimate the probability of future equipment failures. Prescriptive analytics can also be used to recommend when maintenance should be performed and which equipment should be prioritized. The final goal is to use data to reduce unplanned downtime and improve maintenance decisions.
